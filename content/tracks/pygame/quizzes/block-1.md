## Что делает команда `git commit`?

- [ ] отправляет файлы на сервер
- [x] сохраняет снимок файлов в историю
- [ ] скачивает работу других ребят

> `commit` — это снимок. Отправляет на сервер другая команда, `push`. Их легко перепутать, потому что обычно мы делаем их подряд.

## Что вернёт `input`, если ввести число 12?

- [ ] число 12, с ним можно сразу считать
- [x] текст «12», считать с ним нельзя
- [ ] `True`

> `input` всегда возвращает текст. Чтобы считать, нужен `int()`.

## Что напечатает программа?

```python
age = input("Сколько тебе лет? ")
print(age + age)
```

Если ввести `13`:

- [ ] 26
- [x] 1313
- [ ] ошибка

> Текст склеивается, а не складывается. Сначала нужно превратить его в число: `int(input(...))`.

## Зачем нужен `int()`?

- [x] превращает текст в целое число
- [ ] округляет дробное число до целого
- [ ] печатает число на экране

> `int("13")` даёт число 13. Округлением занимается другая функция, а печатает `print`.

## Чем `=` отличается от `==`?

- [ ] `=` сравнивает, `==` кладёт значение в переменную
- [x] `=` кладёт значение в переменную, `==` сравнивает
- [ ] разницы нет, можно писать любой

> `x = 5` — положить. `x == 5` — спросить. Перепутаешь — программа не упадёт, но будет вести себя странно, и это трудно заметить.

## Что делает `break`?

- [ ] пропускает одну итерацию и идёт дальше
- [x] немедленно выходит из цикла
- [ ] начинает цикл заново

> `break` выкидывает из цикла сразу. Если забыть его в игре «угадай число», цикл не закончится никогда.

## Сколько раз выполнится тело цикла?

```python
for i in range(3):
    print("шаг")
```

- [ ] 2 раза
- [x] 3 раза
- [ ] 4 раза

> `range(3)` даёт 0, 1 и 2 — три числа. Отсчёт идёт с нуля, поэтому «до трёх» означает три повтора.

## Что напечатает программа?

```python
x = 2
while x < 5:
    x = x + 1
print(x)
```

- [ ] 4
- [x] 5
- [ ] 2

> Цикл повторяется, пока `x` меньше пяти. Как только он стал равен пяти, условие перестало выполняться и цикл закончился.

## С какого номера начинаются элементы списка?

```python
snake = [(5, 5), (4, 5), (3, 5)]
```

- [x] с нуля
- [ ] с единицы
- [ ] зависит от длины списка

> Первый элемент — `snake[0]`. Смещение на единицу — самая частая ошибка при работе со списками.

## Что вернёт `snake[-1]` для того же списка?

- [ ] первый элемент `(5, 5)`
- [x] последний элемент `(3, 5)`
- [ ] ошибку, отрицательных номеров не бывает

> Отрицательный номер считается с конца. Это удобно, когда нужен последний элемент, а длину считать не хочется.

## Что нужно сделать, чтобы работа попала в общий репозиторий?

- [ ] сохранить файл в PyCharm
- [ ] сделать коммит
- [x] отправить изменения кнопкой `Push`

> Коммит делает снимок только у тебя на ноутбуке. В общий репозиторий работа попадает после `Push`. Правило курса: нет `push` — нет сдачи.

## Почему в классе нужно запускать `select-me` перед работой?

- [ ] он обновляет PyCharm
- [x] он подписывает коммиты твоим именем
- [ ] он подключает библиотеку pygame

> Ноутбуки общие, учётка Windows одна на всех. Без `select-me` все коммиты класса будут подписаны одним человеком, и история превратится в кашу.

## В списке пять клеток. Что вернёт `snake[:-1]`?

- [x] первые четыре клетки
- [ ] последние четыре клетки
- [ ] все пять клеток

> Срез идёт от начала и не доходит до последнего элемента. Запись `[:-1]` читается «от нулевого до последнего, не включая последний».

## В списке пять клеток. Что вернёт `snake[1:3]`?

- [ ] три элемента: с номерами 1, 2 и 3
- [x] два элемента: с номерами 1 и 2
- [ ] один элемент: с номером 1

> Конечный номер в срез не входит. Это редкое правило приходится запоминать, но у него есть причина: при таком правиле `snake[:2]` и `snake[2:]` вместе дают весь список без пропусков и повторов.

## Что делает запись `a, b = b, a`?

- [ ] сравнивает значения `a` и `b`
- [x] меняет значения `a` и `b` местами
- [ ] присваивает обеим переменным значение `b`

> Python сначала вычисляет правую часть целиком, получает пару значений и только потом раскладывает её по переменным. Поэтому третья переменная не нужна.
