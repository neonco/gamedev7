## Цель

- Проверять выход за границы поля.
- Проверять столкновение с собственным телом.
- Понять, почему последнюю клетку тела не считаем.
- Остановить игру, когда змейка погибла.

## Артефакт

Змейка умирает, упёршись в стену или укусив себя. Игра замирает, змейка остаётся на экране, окно не закрывается.

## Разбор

### Стена

Поле — это клетки от `0` до `COLS - 1` по горизонтали и от `0` до `ROWS - 1` по вертикали. Всё, что за этими пределами, — стена.

```python
if head[0] < 0 or head[0] >= COLS or head[1] < 0 or head[1] >= ROWS:
    ...умерла...
```

Обрати внимание на `>=`, а не `>`. Последняя допустимая клетка — `COLS - 1`, значит `COLS` уже за границей. Это та самая ошибка на единицу, о которой мы говорили в [[06]].

### Укус себя

Голова не должна попадать в клетку, которую занимает тело. Тело у нас — весь список, кроме головы:

```python
if head in snake[:-1]:
    ...умерла...
```

`snake[:-1]` — это весь список без последнего элемента. Стоп, почему без последнего? Последний элемент — это хвост, и он тоже часть тела.

### Почему хвост не считается

Тонкость, из-за которой змейки в играх умирают «на ровном месте».

Посмотри на шаг: сначала мы добавляем новую голову, и только потом убираем хвост. Значит, **в тот момент, когда голова встаёт на клетку хвоста, хвост уже уходит** — эта клетка освобождается. Столкновения нет, и умирать нельзя.

Если считать весь список целиком, змейка будет погибать, заходя на клетку, которую покидает её собственный хвост. Игрок этого не поймёт: на экране он ничего не задел. Особенно заметно на короткой змейке, которая крутится на маленьком пятачке.

> [!важно]
> Поэтому проверяем `snake[:-1]` — всё тело, кроме хвоста. А вот собственную голову и шею задевать нельзя: они никуда не уходят.

### Остановка игры

Когда змейка погибла, игра не должна продолжаться. Но и окно закрывать нельзя: игрок должен увидеть, что случилось.

Вводим переменную `alive` — «жива ли»:

```python
if alive:
    ...шаги и еда...
```

Обновление выполняется только пока `alive` истинно. Отрисовка — всегда, поэтому погибшая змейка остаётся видимой.

Функция `move` теперь сообщает три вещи: новую змейку, съела ли еду и жива ли:

```python
return snake, ate, alive
```

## Код

Замени `move` на версию с проверками:

```python
def move(snake, direction, food):
    """Один шаг змейки.

    Возвращает новую змейку, съела ли она еду и жива ли.
    """
    head_x, head_y = snake[0]
    dx, dy = direction
    head = (head_x + dx, head_y + dy)

    # упёрлась в стену
    if head[0] < 0 or head[0] >= COLS or head[1] < 0 or head[1] >= ROWS:
        return snake, False, False

    # укусила себя. Последнюю клетку не считаем: хвост в этот же шаг уходит
    if head in snake[:-1]:
        return snake, False, False

    snake = [head] + snake
    ate = head == food
    if not ate:
        snake.pop()
    return snake, ate, True
```

Добавь рисование надписи о конце игры:

```python
def draw_game_over():
    text = font.render("Игра окончена", True, TEXT_COLOR)
    rect = text.get_rect(center=(WIDTH // 2, HEIGHT // 2))
    pygame.draw.rect(screen, BG_LIGHT, rect.inflate(30, 20))
    screen.blit(text, rect)
```

`get_rect(center=...)` — способ поставить картинку по центру: сначала берём её прямоугольник, потом говорим, где должен быть его центр. `inflate(30, 20)` делает подложку чуть больше текста, чтобы буквы не сливались с полем.

Перед циклом заведи признак жизни:

```python
alive = True
```

Измени обновление:

```python
    if alive:
        now = pygame.time.get_ticks()
        if now - last_move >= START_TICK:
            last_move = now
            direction = pending
            snake, ate, alive = move(snake, direction, food)
            if ate:
                score += 1
                food = new_food(snake)
```

И в отрисовку добавь надпись:

```python
    draw_board()
    draw_food(food)
    draw_snake(snake)
    draw_score(score)
    if not alive:
        draw_game_over()
    pygame.display.flip()
```

Проверь оба вида смерти: врежься в стену и укуси себя на длинной змейке. В обоих случаях змейка должна замереть, а окно — остаться открытым.

### Запомнить

- Границы: допустимы номера от 0 до `COLS - 1`, поэтому в проверке стоит `>=`.
- Укус себя проверяется как `snake[:-1]` — **без последнего элемента**.
- Хвост уходит в тот же шаг, поэтому заходить на его клетку можно.
- `alive` управляет обновлением, но не отрисовкой.

## Для учителя

- Случай с хвостом стоит показать специально: сделай длинную змейку, заведи её в плотный вираж и покажи, что заход на клетку хвоста безопасен. Потом на минуту поменяй `[:-1]` на весь список — и станет видно, как игра ломается.
- Проверка границ — хорошее место вспомнить ошибку на единицу. Пусть кто-нибудь специально напишет `>` и посмотрит, что будет у правой и нижней стены.
- Смерть о стену у нас — конец игры. В классической змейке иногда делают проход сквозь стены; если кто-то предложит — хорошая домашка на подумать.
