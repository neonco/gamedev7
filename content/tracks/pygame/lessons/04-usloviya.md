## Разбор

### Сравнение вместо присваивания

Мы уже знаем `=` — «положи в коробку». Для сравнения используется `==` — «равно ли». Это разные вещи, и путать их нельзя:

- `x = 5` — положить пятёрку в `x`.
- `x == 5` — спросить, лежит ли в `x` пятёрка.

Сравнение отвечает на вопрос словом `True` (да) или `False` (нет).

Операторы сравнения: `==` равно, `!=` не равно, `>` больше, `<` меньше, `>=` больше или равно, `<=` меньше или равно.

### Если

```python
if number > secret:
    print("Моё число меньше")
```

Читается так: если условие истинно — выполни то, что с отступом.

Отступ — это не для красоты. В Python он показывает, что относится к условию. Четыре пробела — стандарт. Смешал табы и пробелы — получишь ошибку `IndentationError`, и это одна из самых частых ошибок у новичков.

### Иначе

```python
if number > secret:
    print("Моё число меньше")
elif number < secret:
    print("Моё число больше")
else:
    print("Угадал!")
```

- `elif` — «иначе если». Проверяется, только если предыдущее условие оказалось ложным.
- `else` — «во всех остальных случаях». Идёт последним и условия не имеет.

Порядок важен: Python проверяет ветки сверху вниз и останавливается на первой сработавшей.

### Случайное число

```python
import random
secret = random.randint(1, 100)
```

`import` подключает модуль — набор готовых инструментов. `random.randint(1, 100)` возвращает случайное целое **включая оба конца**: и единицу, и сотню.

## Код

```python
import random

secret = random.randint(1, 100)

print("Я загадал число от 1 до 100.")
number = int(input("Твоя попытка: "))

if number > secret:
    print(f"Моё число меньше. Я загадал {secret}.")
elif number < secret:
    print(f"Моё число больше. Я загадал {secret}.")
else:
    print("Угадал с первого раза!")
```

Запусти несколько раз: число каждый раз новое. Потом поменяй границы и посмотри, что изменится.

> [!важно]
> Сейчас у игрока одна попытка, и это скучно. Ровно поэтому следующий урок — циклы: мы дадим игроку пытаться, пока не угадает.

### Запомнить

- `=` кладёт значение в переменную, `==` **сравнивает**. Это разные вещи.
- Операторы сравнения: `==` `!=` `>` `<` `>=` `<=`
- **Отступ** — не украшение, а часть синтаксиса. Четыре пробела.
- `random.randint(1, 100)` включает **оба** конца: и единицу, и сотню.

### Если что-то не так

- `IndentationError` — съехали отступы.
- Программа всегда отвечает одинаково — сравнение написано через `=` вместо `==`.
