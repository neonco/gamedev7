## Цель

- Ставить еду в случайную свободную клетку.
- Проверять, что голова попала на еду.
- Понять, почему хвост убирается не всегда.
- Вывести счёт на экран.

## Артефакт

На поле лежит красный кружок. Змейка его съедает, становится длиннее на одну клетку, счёт увеличивается, а еда появляется в новом месте.

## Разбор

### Еда не должна появляться внутри змейки

Первое, что приходит в голову: взять случайные координаты.

```python
food = (random.randint(0, COLS - 1), random.randint(0, ROWS - 1))
```

Это работает, но иногда еда оказывается прямо в теле змейки. Тогда её невозможно съесть, и игра застревает: счёт не растёт, змейка не удлиняется.

Правильно — сначала собрать список свободных клеток, а потом выбрать из него:

```python
def new_food(snake):
    free = []
    for x in range(COLS):
        for y in range(ROWS):
            if (x, y) not in snake:
                free.append((x, y))
    if not free:
        return None
    return random.choice(free)
```

`random.choice` берёт случайный элемент из списка. Поле у нас небольшое — триста клеток, — поэтому перебрать все и не страшно.

Случай `if not free` — это победа: свободных клеток не осталось, змейка заняла всё поле. Пока мы просто возвращаем `None`, а рисовать еду в этом случае не будем.

### Рост: хвост убираем не всегда

Вспомни шаг змейки: добавили новую голову, убрали хвост. Если съели еду, хвост убирать нельзя — иначе длина не изменится и рост не произойдёт.

```python
snake = [head] + snake
ate = head == food
if not ate:
    snake.pop()
```

`ate` — «съела ли». Сравнение головы с едой даёт `True` или `False`, и это ровно то, что нужно: если `ate` истинно, хвост остаётся и змейка становится на клетку длиннее.

### Функция возвращает три вещи

Раньше `move` возвращала только змейку. Теперь ей нужно ещё сообщить, съела ли она еду:

```python
def move(snake, direction, food):
    ...
    return snake, ate
```

Функция может возвращать несколько значений сразу — они разделяются запятыми. Забирать их тоже надо по порядку:

```python
snake, ate = move(snake, direction, food)
```

### Счёт и текст на экране

Чтобы показать счёт, нужен шрифт. В pygame это две строки: создать шрифт один раз, потом рисовать им текст.

```python
font = pygame.font.Font(None, 30)

def draw_score(score):
    text = font.render("Счёт: " + str(score), True, TEXT_COLOR)
    screen.blit(text, (10, 8))
```

- `pygame.font.Font(None, 30)` — шрифт по умолчанию размером 30. `None` означает «возьми стандартный», и это избавляет от поиска шрифта по имени на разных компьютерах.
- `render` превращает текст в **картинку**. В pygame нельзя просто «написать текст на экране» — сначала текст становится картинкой, потом картинка кладётся на экран.
- `True` — сглаживание букв, чтобы не было зубцов.
- `blit` кладёт картинку в точку `(10, 8)` — это левый верхний угол экрана.
- `str(score)` нужен потому, что склеивать можно только строки с строками. Число сначала превращаем в текст.

### Еда как кружок

Еду нарисуем овалом внутри клетки, чтобы отличалась от змейки:

```python
def draw_food(food):
    if food is None:
        return
    rect = cell_rect(food)
    rect.inflate_ip(-8, -8)
    pygame.draw.ellipse(screen, FOOD_COLOR, rect)
```

`inflate_ip(-8, -8)` уменьшает прямоугольник на 8 пикселей с каждой стороны, сохраняя центр. Получается аккуратный кружок по центру клетки, а не квадрат во всю клетку.

Замени `move` на версию с едой:

```python
def move(snake, direction, food):
    """Один шаг змейки. Возвращает новую змейку и съела ли она еду."""
    head_x, head_y = snake[0]
    dx, dy = direction
    head = (head_x + dx, head_y + dy)

    snake = [head] + snake
    ate = head == food
    if not ate:
        snake.pop()
    return snake, ate
```

## Шпаргалка

### Что должно работать

- Еда появляется и никогда не лежит внутри змейки
- Съела — выросла ровно на одну клетку, счёт увеличился
- Счёт виден на экране

### Запомнить

- Еду ставим только в **свободную** клетку, а не в случайные координаты.
- Рост — это **не убирать хвост**. `pop()` стоит под условием.
- Текст в pygame сначала становится картинкой: `font.render`, потом `blit`.
- `inflate_ip(-8, -8)` уменьшает прямоугольник, сохраняя центр.

## Для учителя

- `if not free: return None` — заготовка на победу. Не углубляйся, но скажи, что случай учтён.
- Важно, чтобы все увидели: рост — это отсутствие `pop()`, а не отдельная команда «удлинись». Это понимание пригодится и в мультиплеере.
- Про `render` и `blit` достаточно одной мысли: текст сначала становится картинкой. Дети часто пытаются «напечатать» текст и удивляются, что нужен шрифт.
