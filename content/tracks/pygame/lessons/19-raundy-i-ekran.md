## Цель

- Понять, что у игры есть состояния: играем, показываем итог, матч окончен.
- Не начинать новый раунд мгновенно, а дать игрокам увидеть результат.
- Считать победы в раундах отдельно от съеденной еды.
- Научиться рисовать панель по центру экрана.

## Артефакт

После гибели змейки игра останавливается и показывает, кто взял раунд. Пробел начинает следующий. Внизу экрана виден счёт побед обоих игроков.

## Разбор

### Состояния игры

До сих пор у нас было просто «играем». Теперь нужно ещё «показываем итог» и «матч окончен». Это разные режимы, и в каждом игра ведёт себя по-своему.

Заведём переменную состояния:

```python
state = "play"      # play | between | match_over
```

- `play` — идёт раунд: змейки двигаются, клавиши управляют.
- `between` — раунд закончился, ждём пробел.
- `match_over` — матч закончился, ждём R.

Ввод, обновление и отрисовка теперь смотрят на `state` и делают разное. Это первый шаг к настоящей машине состояний, которая есть в любой игре: меню, игра, пауза, конец.

### Почему нельзя начинать новый раунд сразу

Соблазн простой: змейка погибла — тут же создаём новую и играем дальше. Но тогда игроки не поймут, что произошло. Кто победил? Почему змейка исчезла?

Поэтому между раундами игра **ждёт**. Панель с результатом висит, пока кто-нибудь не нажмёт пробел.

> [!подсказка]
> В настоящих играх пауза после смерти делается не только для удобства: она даёт игроку перевести дух и понять, что он сделал не так. Мелочь, а играть становится приятнее.

### Победы в раундах — не то же самое, что еда

У нас теперь два разных счёта:

- `snake.eaten` — сколько еды съела змейка **в этом раунде**;
- `wins` — сколько **раундов** выиграл каждый игрок.

Путать их нельзя: можно съесть больше еды и всё равно проиграть раунд, врезавшись в стену. Победа в раунде — за выживание, еда нужна только для ничейных случаев.

`wins` — это список из двух чисел, по одному на игрока:

```python
wins = [0, 0]
...
wins[winner] += 1
```

### Панель по центру

Чтобы показать результат, нарисуем прямоугольник и текст в нём:

```python
def draw_panel(lines, subtitle=None):
    """Панель по центру экрана: результат раунда, конец матча."""
    height = 40 + len(lines) * 34 + (34 if subtitle else 0)
    panel = pygame.Rect(0, 0, WIDTH - 120, height)
    panel.center = (WIDTH // 2, HEIGHT // 2)
    pygame.draw.rect(screen, PANEL_COLOR, panel)
    pygame.draw.rect(screen, TEXT_COLOR, panel, 2)

    y = panel.top + 20
    for line in lines:
        text = big_font.render(line, True, TEXT_COLOR)
        screen.blit(text, (WIDTH // 2 - text.get_width() // 2, y))
        y += 34
    if subtitle:
        text = font.render(subtitle, True, TEXT_COLOR)
        screen.blit(text, (WIDTH // 2 - text.get_width() // 2, y + 4))
```

Обрати внимание на расчёт высоты: панель подстраивается под число строк. Иначе пришлось бы заводить отдельную панель на каждый случай.

`pygame.Rect(0, 0, ширина, высота)` создаёт прямоугольник в углу, а `panel.center = ...` переносит его в центр экрана. Так удобнее, чем считать координаты вручную.

## Шпаргалка

### Что должно работать

- Раунд заканчивается и показывает итог
- Пробел начинает следующий раунд
- Внизу виден счёт побед обоих игроков

### Запомнить

- **Состояние игры** — переменная `state`: `play`, `between`, `match_over`. От неё зависит и ввод, и обновление, и отрисовка.
- Новый раунд начинается **по пробелу**, а не сразу: игроки должны увидеть результат.
- `wins` — победы в раундах, `eaten` — еда за раунд. Это разные числа.
- `panel.center = (x, y)` ставит прямоугольник по центру: считать координаты вручную не надо.
