## Цель

- Посадить змейку на поле как список клеток.
- Понять, что скорость игры и частота кадров — разные вещи.
- Освоить игровое время через `pygame.time.get_ticks()`.
- Сделать ход змейки отдельной функцией.

## Артефакт

Голова ползёт вправо ровными шагами, примерно семь шагов в секунду. Если поменять `FPS`, скорость шагов не изменится.

## Разбор

### Змейка — это список клеток

Мы уже знаем, что тело змейки удобно хранить списком. Начинаем с одной клетки — головы:

```python
snake = [(COLS // 2, ROWS // 2)]
direction = (1, 0)
```

`direction` — это пара чисел: на сколько клеток сдвинуться по горизонтали и по вертикали. `(1, 0)` — на одну вправо, `(0, -1)` — вверх, `(-1, 0)` — влево, `(0, 1)` — вниз.

Почему `//`? Потому что середина поля может оказаться дробной, а клетки нумеруются целыми. `//` отбрасывает дробную часть.

### Шаг змейки

Голова идёт вперёд, хвост подтягивается. В терминах списка это «добавить новую голову в начало»:

```python
head = (snake[0][0] + dx, snake[0][1] + dy)
snake = [head] + snake
snake.pop()
```

`pop()` без аргумента убирает последний элемент — старый хвост. Пока змейка не ест, длина не меняется: одна клетка добавилась, одна ушла.

Пока еды нет, хвост убирать можно всегда. На уроке [[11]] появится условие: если съела — хвост остаётся и змейка растёт.

### Две скорости — не путать

Самый важный момент урока.

Экран перерисовывается **60 раз в секунду**, чтобы движение выглядело плавно. Но змейка не должна делать 60 шагов в секунду — это будет мельтешение. Ей нужно примерно **6–7 шагов в секунду**.

Значит, шаг змейки нельзя делать в каждом кадре. Нужен отдельный счёт времени:

```python
TICK = 150                       # миллисекунд между шагами
last_move = pygame.time.get_ticks()

...
    now = pygame.time.get_ticks()
    if now - last_move >= TICK:
        last_move = now
        ...шаг...
```

`pygame.time.get_ticks()` возвращает, сколько миллисекунд прошло с запуска игры. Мы запоминаем момент последнего шага и сравниваем: если прошло больше `TICK` — пора шагать и запомнить новое время.

150 миллисекунд — это примерно 6–7 шагов в секунду.

> [!важно]
> Если бы мы двигали змейку в каждом кадре, скорость игры зависела бы от мощности компьютера: на быстрой машине змейка летала бы, на слабой еле ползла. Это классическая ошибка новичков. Игровое время считают отдельно от кадров — и мы это только что сделали.

### Как нарисовать змейку

```python
def draw_snake(snake):
    for i, cell in enumerate(snake):
        if i == 0:
            color = SNAKE_HEAD
        else:
            color = SNAKE_BODY
        rect = cell_rect(cell)
        pygame.draw.rect(screen, color, rect)
        pygame.draw.rect(screen, BG_DARK, rect, 2)
```

`enumerate` даёт и номер элемента, и сам элемент. Номер нужен, чтобы покрасить голову отдельным цветом: `i == 0` — это голова, потому что мы условились хранить её первой.

Последняя строка рисует рамку: третий аргумент `2` означает толщину линии. Без рамки клетки змейки сливаются в одно пятно.

## Код

Добавь цвета и настройку скорости:

```python
START_TICK = 150          # миллисекунд между шагами змейки

SNAKE_BODY = (60, 90, 200)
```

Функцию рисования змейки и функцию шага:

```python
def draw_snake(snake):

        rect = cell_rect(cell)
        pygame.draw.rect(screen, color, rect)
        pygame.draw.rect(screen, BG_DARK, rect, 2)


def move(snake, direction):
    """Один шаг змейки. Возвращает новую змейку."""
    head_x, head_y = snake[0]
    dx, dy = direction
    head = (head_x + dx, head_y + dy)

    snake = [head] + snake
    snake.pop()
    return snake
```

### Файл целиком

```python
import pygame

# ---------- настройки ----------
CELL = 40
COLS = 20
ROWS = 15
WIDTH = COLS * CELL
HEIGHT = ROWS * CELL
FPS = 60
START_TICK = 150          # миллисекунд между шагами змейки

BG_LIGHT = (170, 215, 81)
BG_DARK = (162, 209, 73)
SNAKE_BODY = (60, 90, 200)
SNAKE_HEAD = (40, 60, 160)

pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Змейка")
clock = pygame.time.Clock()


def cell_rect(cell):
    """Клетка поля -> прямоугольник на экране."""
    x, y = cell
    return pygame.Rect(x * CELL, y * CELL, CELL, CELL)


def draw_board():
    """Шахматное поле."""
    for row in range(ROWS):
        for col in range(COLS):
            if (row + col) % 2 == 0:
                color = BG_LIGHT
            else:
                color = BG_DARK
            pygame.draw.rect(screen, color, cell_rect((col, row)))


def draw_snake(snake):
    for i, cell in enumerate(snake):
        if i == 0:
            color = SNAKE_HEAD
        else:
            color = SNAKE_BODY
        rect = cell_rect(cell)
        pygame.draw.rect(screen, color, rect)
        pygame.draw.rect(screen, BG_DARK, rect, 2)


def move(snake, direction):
    """Один шаг змейки. Возвращает новую змейку."""
    head_x, head_y = snake[0]
    dx, dy = direction
    head = (head_x + dx, head_y + dy)

    snake = [head] + snake
    snake.pop()
    return snake


snake = [(COLS // 2, ROWS // 2)]
direction = (1, 0)
last_move = pygame.time.get_ticks()

running = True
while running:
    # 1. ВВОД
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # 2. ОБНОВЛЕНИЕ
    now = pygame.time.get_ticks()
    if now - last_move >= START_TICK:
        last_move = now
        snake = move(snake, direction)

    # 3. ОТРИСОВКА
    draw_board()
    draw_snake(snake)
    pygame.display.flip()

    clock.tick(FPS)

pygame.quit()
```

Проверь опыт: поменяй `FPS` на 20 и на 120. Плавность изменится, а скорость змейки останется прежней. Потом поменяй `START_TICK` на 400 — змейка поползёт медленно, а экран останется плавным.

## Шпаргалка

### Что должно работать

- Змейка из одной клетки ползёт вправо ровными шагами
- Если поменять `FPS`, скорость змейки не меняется
- Если поменять `START_TICK`, скорость меняется

### Запомнить

- **Частота кадров и скорость игры — разные скорости.** Кадры рисуют, шаги двигают.
- `pygame.time.get_ticks()` — сколько миллисекунд прошло с запуска.
- `last_move` помнит момент прошлого шага; шаг делается, когда прошло больше `TICK`.
- Шаг змейки: добавить голову в начало списка, убрать хвост через `pop()`.
