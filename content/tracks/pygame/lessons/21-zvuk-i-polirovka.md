## Цель

- Сгенерировать звуковые файлы кодом, без готовых ассетов.

## Артефакт

Змейка издаёт звук, когда ест, когда раунд заканчивается и когда определился победитель. Если микшера нет, игра работает молча и не падает.

## Разбор

### Звук — это числа

Мы привыкли, что картинка — это пиксели, то есть числа. Со звуком то же самое: это последовательность чисел, которые описывают колебание.

- **Частота** — сколько колебаний в секунду. Больше частота — выше писк.
- **Громкость** — размах колебания.
- **Длительность** — сколько чисел в последовательности.

Значит, звук можно не скачивать, а посчитать:

```python
def write_beep(path, frequency, milliseconds, volume=0.35, sample_rate=22050):
    frames = int(sample_rate * milliseconds / 1000)
    data = array.array("h")
    for i in range(frames):
        value = math.sin(2 * math.pi * frequency * i / sample_rate)
        fade = 1 - i / frames
        data.append(int(value * fade * volume * 32767))
    with wave.open(str(path), "w") as handle:
        handle.setnchannels(1)
        handle.setsampwidth(2)
        handle.setframerate(sample_rate)
        handle.writeframes(data.tobytes())
```

Разбери по частям:

- `math.sin(...)` даёт плавную волну — от `-1` до `1`.
- Умножение на `32767` превращает её в целые числа: столько влезает в 16 бит.
- `fade` уменьшает громкость к концу сигнала. Без этого на конце слышен щелчок: резкий обрыв звука.
- Модуль `wave` записывает всё это в обычный WAV-файл.

Три сигнала — три характера: короткий высокий для еды, низкий и длинный для аварии, средний для победы.

```python
        beeps = {
            "eat": (880, 90),
            "crash": (160, 350),
            "win": (660, 400),
        }
```

### Звук не должен ломать игру

В классе бывают машины без звуковой карты или с выключенным звуком. Если игра упадёт из-за этого, будет обидно: всё работало, а тут звук.

Поэтому загрузка звуков спрятана в защиту:

```python
    try:
        pygame.mixer.init()
        ...
    except Exception:
        return {}
```

`try` означает «попробуй выполнить», `except` — «если не получилось, сделай вот это». Мы уже встречали эту конструкцию, когда говорили про ошибки. Здесь она по делу: звук — не то, ради чего стоит ронять игру.

Проверить это можно так: в словаре нет нужного звука — играем молча.

```python
def play(sounds, name):
    sound = sounds.get(name)
    if sound is not None:
        sound.play()
```

`get` не падает, если ключа нет, — возвращает `None`. Это отличие от обращения по квадратным скобкам: `sounds[name]` при отсутствии ключа дал бы `KeyError`.

### Состояние для отладки

В [[15]] мы добавили `__str__`. Сейчас самое время им воспользоваться: когда игра ведёт себя странно, хочется посмотреть, что с ней происходит.

```python
print(player1)
```

напечатает `Игрок 1: длина 4, направление (1, 0), съедено 2, жива True`. Не нужно вручную собирать строку из полей — это делает `__str__`.

Добавь генерацию и загрузку звуков:

```python
SOUND_DIR = pathlib.Path(__file__).resolve().parent / "sounds"


def write_beep(path, frequency, milliseconds, volume=0.35, sample_rate=22050):
    """Записать короткий сигнал в WAV-файл."""
    frames = int(sample_rate * milliseconds / 1000)
    data = array.array("h")
    for i in range(frames):
        value = math.sin(2 * math.pi * frequency * i / sample_rate)
        fade = 1 - i / frames
        data.append(int(value * fade * volume * 32767))
    with wave.open(str(path), "w") as handle:
        handle.setnchannels(1)
        handle.setsampwidth(2)
        handle.setframerate(sample_rate)
        handle.writeframes(data.tobytes())


def load_sounds():
    """Загрузить звуки, сгенерировав их при первом запуске."""
    sounds = {}
    try:
        pygame.mixer.init()
        SOUND_DIR.mkdir(exist_ok=True)
        beeps = {
            "eat": (880, 90),
            "crash": (160, 350),
            "win": (660, 400),
        }
        for name, (frequency, milliseconds) in beeps.items():
            path = SOUND_DIR / f"{name}.wav"
            if not path.exists():
                write_beep(path, frequency, milliseconds)
            sounds[name] = pygame.mixer.Sound(str(path))
    except Exception:  # без звука игра обязана работать
        return {}
    return sounds


def play(sounds, name):
    """Проиграть звук, если он есть."""
    sound = sounds.get(name)
    if sound is not None:
        sound.play()
```

Включи звуки в игру: загрузи перед циклом и проигрывай в нужных местах.

```python
    sounds = load_sounds()
```

```python
                if step_snakes(snakes, food):
                    play(sounds, "eat")
```

```python

```

```python

```

## Шпаргалка

### Что должно работать

- Три разных звука: еда, авария, победа
- Файлы звуков создаются кодом, если их нет
- Без звуковой карты игра работает молча и не падает

### Запомнить

- **Звук — это числа.** Частота задаёт высоту, размах — громкость, длина последовательности — длительность.
- Затухание в конце сигнала убирает щелчок.
- `try` / `except` — «попробуй, а если не выйдет, сделай запасной вариант». Звук не повод ронять игру.
- `sounds.get(name)` возвращает `None`, если ключа нет, и не падает — в отличие от `sounds[name]`.
- `print(player1)` работает благодаря `__str__` из [[15]].

## Для учителя

- Мысль «звук — это числа» стоит показать наглядно: пусть ребёнок поставит частоту `50` и `2000` и услышит разницу, а потом поставит `volume=1.0` и услышит, что стало громче.
- Защита `try`/`except` — единственное место в курсе, где она уместна по-настоящему. Не позволяй оборачивать в неё всё подряд: проглоченная ошибка прячет проблему.
- Папку `sounds` можно не коммитить: она создаётся сама. Хорошая тренировка — добавить её в `.gitignore`.
