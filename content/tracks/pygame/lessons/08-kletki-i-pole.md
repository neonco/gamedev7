## Цель

- Понять разницу между координатами в клетках и в пикселях.
- Освоить `Rect` — прямоугольник, которым рисуют и проверяют столкновения.
- Научиться выносить повторяющийся код в функцию.
- Нарисовать поле из клеток.

## Артефакт

Окно показывает шахматное поле 20 клеток на 15, каждая клетка 40 пикселей.

## Разбор

### Две системы координат

В пикселях считать неудобно. Змейка живёт по клеткам: «голова в клетке (10, 7)». А `pygame.draw.rect` хочет пиксели: «нарисовать квадрат начиная с точки (400, 280)».

Значит, нужен перевод. Одна функция, которая делает это в одном месте:

```python
def cell_rect(cell):
    x, y = cell
    return pygame.Rect(x * CELL, y * CELL, CELL, CELL)
```

Клетка `(10, 7)` превращается в квадрат со стороной 40 на позиции `(400, 280)`. Дальше весь код работает с клетками, а пиксели считает только эта функция. Если однажды поменяем `CELL` с 40 на 30, ничего больше править не придётся.

> [!важно]
> Правило на весь блок: **внутри логики — только клетки, пиксели появляются только на отрисовке.** Смешаешь — утонешь в умножениях и в поиске ошибок «змейка нарисовалась на полклетки левее».

### Что такое Rect

`pygame.Rect` — прямоугольник. У него есть левый верхний угол и размер.

```python
pygame.Rect(x, y, width, height)
```

Rect умеет полезные вещи: `rect.center`, `rect.right`, `rect.inflate_ip(...)` — изменить размер, сохранив центр. Последнее пригодится для еды: клетка есть, а кружок внутри неё нарисуем чуть меньше.

Функции рисования принимают и Rect, и просто четыре числа. Мы будем использовать `cell_rect` — так кода меньше и он одинаковый.

### Функция вместо повторов

Поле — это двадцать на пятнадцать, то есть триста клеток. Писать триста строк рисования невозможно, поэтому двойной цикл:

```python
for row in range(ROWS):
    for col in range(COLS):
        ...
```

Внешний цикл идёт по строкам, внутренний — по клеткам внутри строки. Это тот же список списков из [[06]], только адреса считаются, а не хранятся в памяти.

Шахматный цвет получается из чётности суммы координат: если `row + col` чётное — один цвет, иначе другой. Именно поэтому клетки чередуются как на шахматной доске.

### Файл целиком

```python
import pygame

# ---------- настройки ----------
CELL = 40                 # размер одной клетки в пикселях
COLS = 20                 # сколько клеток по ширине
ROWS = 15                 # сколько клеток по высоте
WIDTH = COLS * CELL
HEIGHT = ROWS * CELL
FPS = 60

BG_LIGHT = (170, 215, 81)
BG_DARK = (162, 209, 73)

pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Змейка")
clock = pygame.time.Clock()


def cell_rect(cell):
    """Клетка поля -> прямоугольник на экране."""
    x, y = cell
    return pygame.Rect(x * CELL, y * CELL, CELL, CELL)


def draw_board():
    """Шахматное поле."""
    for row in range(ROWS):
        for col in range(COLS):
            if (row + col) % 2 == 0:
                color = BG_LIGHT
            else:
                color = BG_DARK
            pygame.draw.rect(screen, color, cell_rect((col, row)))


running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    draw_board()
    pygame.display.flip()

    clock.tick(FPS)

pygame.quit()
```

### Запомнить

- **Клетки и пиксели — разные вещи.** Логика работает в клетках, пиксели появляются только на отрисовке.
- `cell_rect(клетка)` переводит клетку в прямоугольник. Она одна считает пиксели.
- `pygame.Rect` — прямоугольник: x, y, ширина, высота.
- Шахматный узор получается из чётности `row + col`.

## Для учителя

- Здесь закладывается главная привычка блока: логика в клетках, пиксели только при отрисовке. Если её не закрепить, дальше дети будут путаться в координатах.
- Полезно дать задачу «поменяй CELL и посмотри, что будет». Если код правильный, меняется только размер клетки; если где-то пиксели считались вручную, картинка поедет — и это лучшая демонстрация, зачем нужна `cell_rect`.
- Слово Rect стоит проговорить как «прямоугольник». Подробности (`center`, `inflate`) пока не нужны, они понадобятся на еде и столкновениях.
