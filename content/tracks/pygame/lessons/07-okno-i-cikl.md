## Разбор

### Что такое pygame-ce

Это библиотека: готовый набор инструментов для игр. Окно, рисование, звук, столкновения — всё уже написано, нам остаётся этим пользоваться. Мы договорились, что библиотека установлена в проект на первом уроке, поэтому проверяем сразу:

```python
import pygame
```

Если эта строка проходит без ошибок — можно работать.

### Игровой цикл

Игра отличается от обычной программы тем, что **не заканчивается сама**. Обычная программа: посчитала, напечатала, завершилась. Игра: пока окно открыто, она должна реагировать на клавиши и перерисовывать экран — десятки раз в секунду.

Поэтому главная часть любой игры — бесконечный цикл:

```python
running = True
while running:
    ...
```

Внутри цикла всегда три шага, и порядок важен:

1. **Ввод** — что нажал игрок и не закрыл ли он окно.
2. **Обновление** — что изменилось в мире игры.
3. **Отрисовка** — показать новое состояние на экране.

Если перепутать порядок и рисовать до обновления, ты будешь показывать прошлый кадр — картинка начнёт отставать.

### Закрытие окна

Крестик в углу окна — это не «выключить программу», а **событие**, которое приходит в игру как и любое нажатие клавиши. Его надо обработать:

```python
for event in pygame.event.get():
    if event.type == pygame.QUIT:
        running = False
```

`pygame.event.get()` отдаёт всё, что случилось с прошлого кадра. Нет события — цикл крутится дальше. Если не обработать `QUIT`, крестик не сработает, и окно придётся закрывать силой.

### Частота кадров

Если дать циклу крутиться свободно, он выполнится миллионы раз в секунду и займёт процессор целиком. Ноутбук начнёт греться и гудеть, а игра не станет лучше: человеческий глаз всё равно не различит больше шестидесяти кадров в секунду.

Поэтому в конце цикла ставим ограничитель:

```python
clock.tick(60)
```

Это значит «не чаще шестидесяти раз в секунду». `clock` создаётся один раз в начале.

> [!важно]
> Не путай две скорости: **60 кадров в секунду** — как часто перерисовывается экран, и **скорость змейки** — как часто она делает шаг. Это разные вещи, и во второй половине блока мы их разведём.

### Цвета

Цвет в pygame — это три числа от 0 до 255: сколько красного, зелёного и синего.

```python
BG = (170, 215, 81)   # салатовый
```

Ноль — цвет отсутствует, 255 — на полную. `(0, 0, 0)` — чёрный, `(255, 255, 255)` — белый, `(255, 0, 0)` — красный.

## Код

```python
import pygame

# ---------- настройки ----------
CELL = 40                 # размер одной клетки в пикселях
COLS = 20                 # сколько клеток по ширине
ROWS = 15                 # сколько клеток по высоте
WIDTH = COLS * CELL
HEIGHT = ROWS * CELL
FPS = 60                  # сколько раз в секунду обновляется экран

BG = (170, 215, 81)       # цвет поля, три числа: красный, зелёный, синий

pygame.init()
screen = pygame.display.set_mode((WIDTH, HEIGHT))
pygame.display.set_caption("Змейка")
clock = pygame.time.Clock()

running = True
while running:
    # 1. ВВОД
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    # 2. ОБНОВЛЕНИЕ (пока пусто — обновлять нечего)

    # 3. ОТРИСОВКА
    screen.fill(BG)
    pygame.display.flip()

    clock.tick(FPS)

pygame.quit()
```

Разбери по частям:

- `set_mode((WIDTH, HEIGHT))` — создаёт окно. Скобки внутри скобок не опечатка: размер окна — это пара чисел.
- `set_caption` — надпись в заголовке окна.
- `screen.fill(BG)` — залить весь экран одним цветом. Каждый кадр заново, потому что старый рисунок остаётся.
- `pygame.display.flip()` — показать нарисованное. Без него экран останется чёрным.

Запусти и убедись: окно открывается, крестик работает, вентилятор молчит.

> [!подсказка]
> Мы сразу задали поле не в пикселях, а в клетках: `COLS` и `ROWS`. Змейка живёт по клеткам, и так удобнее считать. Ширина в пикселях получается умножением.
