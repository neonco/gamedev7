## Цель

- Установить Python, PyCharm, pygame-ce и Git.
- Понять, зачем нужен интерпретатор, если есть среда разработки.
- Создать проект и запустить первую программу.
- Убедиться, что библиотека подключена именно к проекту, а не «к компьютеру вообще».

## Артефакт

Программа печатает приветствие и версию pygame. Если обе строки появились — установка закончена.

## Разбор

### Что мы ставим и зачем

**Python** — интерпретатор. Это программа, которая читает твой код и выполняет его. Без неё не запустится ничего, и PyCharm сам код не исполняет: он передаёт файл интерпретатору.

**PyCharm** — среда разработки. Редактор, запуск, подсказки, отладка и работа с git в одном окне. Весь курс мы работаем только в ней, терминал трогать не обязательно.

**pygame-ce** — библиотека для игр. Это готовый набор инструментов: окно, спрайты, звук, столкновения. Нам не придётся писать рисование с нуля.

**Git** — система контроля версий. Она запоминает историю проекта: что менялось, кем и когда. Сегодня мы её только ставим, а работать начнём на следующем уроке — там же выяснится, зачем она нужна.

### Где взять установщики

Все четыре программы лежат в одном месте — в [общем хранилище курса](https://drive.google.com/drive/folders/14iH8HAVOFjoYy6t9aE59ralOA4hpEHMQ?usp=sharing). Внутри две папки: **Windows** и **macOS**. Открой ту, что подходит твоему компьютеру, и поставь оттуда всё по порядку.

Скачивать из интернета ничего не нужно: в наборе лежат готовые установщики, и они проверены — те самые версии, с которыми мы будем работать весь год.

> [!подсказка]
> Ставь программы **по одной** и не переходи к следующей, пока предыдущая не поставилась. Так понятно, что именно пошло не так, если что-то не получится.

### Ловушка, из-за которой чаще всего ничего не работает

При создании проекта PyCharm делает для него **отдельное окружение** — папку со своей копией Python и своими библиотеками. Это называется виртуальным окружением, и сделано это специально: чтобы библиотеки одного проекта не мешали другому.

Отсюда главное следствие урока: **библиотека ставится в проект, а не в компьютер**. Если поставить pygame-ce «вообще», проект его не увидит и упадёт с ошибкой:

```
ModuleNotFoundError: No module named 'pygame'
```

Правильно — ставить в тот интерпретатор, который выбран в проекте. Как именно, разберём в разделе «Код».

### Про версии

pygame-ce требует Python 3.10 или новее. В коде библиотека называется по-старому:

```python
import pygame
```

Писать `import pygame_ce` не нужно — такого модуля не существует, и это частая ошибка.

## Код

Создай в проекте файл `hello.py`:

```python
print("Привет! Я запускаюсь из PyCharm.")

# Проверяем, что библиотека для игр подключена к проекту
import pygame
print("pygame-ce версии:", pygame.version.ver)
```

Запуск: правой кнопкой по файлу → `Run 'hello'`, либо зелёная кнопка ▶ наверху. Внизу откроется панель `Run` с двумя строками.

Если вторая строка не появилась, а вместо неё `ModuleNotFoundError` — библиотека стоит не в том месте. Ставим её в проект:

1. `File` → `Settings` → `Project: <имя проекта>` → `Python Interpreter`.
2. Нажми `+`, найди `pygame-ce`, установи.
3. Закрой настройки и запусти файл заново.

> [!подсказка]
> Тот же результат даёт вкладка `Terminal` внизу PyCharm — она уже открыта в окружении проекта. Команда `pip install pygame-ce` там сработает правильно, а в обычном системном терминале — скорее всего нет.

> [!ошибка]
> Если при запуске PyCharm пишет, что не настроен интерпретатор, — вернись в `Settings` → `Python Interpreter` и выбери тот, что предлагает сам PyCharm при создании проекта. Не выбирай системный Python из `Program Files`: библиотеки туда ставить неудобно.

### Проверяем Git

Открой вкладку `Terminal` внизу PyCharm и набери:

```bash
git --version
```

В ответ придёт что-то вроде `git version 2.51.0.windows.1`. Это значит, что Git установлен и терминал его видит.

> [!важно]
> После установки Git **перезапусти PyCharm**. Он запоминает окружение при запуске, поэтому свежеустановленную программу его терминал может не увидеть. Это самая частая причина надписи «команда не найдена» сразу после установки.

При установке Git оставь выбранным пункт **`Git from the command line and also from 3rd-party software`**. Он добавляет Git в PATH, без него PyCharm программу не найдёт. Остальные настройки можно не трогать.

## Шпаргалка

### Что должно работать

- PyCharm открывается, проект создан, файл запускается кнопкой ▶
- Программа печатает приветствие и **версию pygame**
- В терминале PyCharm отвечает `git --version`

### Запомнить

- **Интерпретатор** — программа, которая выполняет твой код. Без него PyCharm ничего не запустит.
- **Окружение проекта** — отдельная копия Python и библиотек для одного проекта. Поэтому библиотека ставится **в проект**, а не в компьютер.
- **pygame-ce** — библиотека для игр. В коде пишется `import pygame`.

### Если что-то не так

- `ModuleNotFoundError: No module named 'pygame'` — библиотека стоит не в проекте.
- «команда git не найдена» — PyCharm не перезапущен после установки Git.

## Для учителя

- Главная проверка урока — напечатанная версия pygame. Она доказывает, что библиотека стоит в интерпретаторе проекта, а не в системе. Вторая проверка — ответ `git --version`: она закрывает подготовку к следующему уроку.
- Типичные поломки: PyCharm создал окружение, но `pygame-ce` поставили в системный Python; путь проекта содержит кириллицу или пробелы; антивирус медленно распаковывает установщики; на машине уже стоял старый Python, и PyCharm подхватил его.
- Не трать время на «добавить Python в PATH». При работе из PyCharm это не критично, а сил на уроке отнимает много.
- Git лежит в общем хранилище курса, интернет для него не нужен. Если на машине нет прав администратора, а установщик их требует, — положи рядом **PortableGit** из того же выпуска Git for Windows: это самораспаковывающийся архив, он разворачивается в папку пользователя без админских прав. Тогда путь до `git.exe` придётся указать в PyCharm вручную: `Settings` → `Version Control` → `Git`.
- Если Git всё равно не поставился, PyCharm при первом обращении к git предложит его скачать. Это запасной путь, а не основной.
- 45 минут на установку у группы с нуля — впритык. Проси тех, кто уже поставил, помогать соседям: это и быстрее, и закрепляет у них самих.
