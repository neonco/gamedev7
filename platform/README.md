# Платформа курса: что подготовить учителю

Здесь лежит всё, что нужно сделать руками до первого урока. Две части: набор файлов для детей и репозиторий класса.

## 1. Что положить на Яндекс.Диск

Одна папка, одна ссылка, которую ты даёшь на первом уроке.

| Файл | Зачем | На что смотреть |
|---|---|---|
| Установщик Python | интерпретатор | **нужна версия 3.10 или новее** — `pygame-ce` не поддерживает старее |
| Установщик PyCharm | среда разработки | один установщик: с версии 2025.1 Community и Professional объединены, ключ Professional не нужен |
| `pygame-ce` | библиотека для игр | ставят на первом уроке из интернета, но лучше положить файл-колесо на случай закрытого PyPI |
| Git for Windows | система контроля версий | обязателен: без него не будет ни клонирования, ни коммитов. На машинах без прав администратора положи рядом PortableGit — см. ниже |

Колесо `pygame-ce` — это файл вида `pygame_ce-2.5.8-cp312-cp312-win_amd64.whl`. Часть `cp312` означает версию Python: она должна совпадать с установщиком, который ты положил. Скачать можно со страницы проекта на PyPI, раздел `Download files`.

Если в классе закрыт PyPI, установка библиотеки идёт из файла:

```
pip install путь\к\pygame_ce-2.5.8-cp312-cp312-win_amd64.whl
```

Команду выполняют в терминале PyCharm — там уже активировано окружение проекта.

## 2. Репозиторий класса

Папка `class-repo/` — это заготовка репозитория. Порядок такой.

**Создай пустой репозиторий на GitHub** с именем вроде `python7-class`. При создании не добавляй ни README, ни `.gitignore` — они у нас свои.

**Заполни список учеников.** Скопируй `class-repo/students.txt.example` в `class-repo/students.txt` и впиши строки вида:

```
ivan-petrov: Иван Петров
anna-sidorova: Анна Сидорова
```

Логин — латиницей, без пробелов. Он станет именем папки и частью подписи коммитов.

**Сгенерируй папки:**

```
cd platform
python3 tools/make_students.py
```

Скрипт создаст `class-repo/students/<логин>/` с личной страницей `README.md` и файлом `name.txt`, из которого `select-me` берёт имя для подписи коммитов. Повторный запуск безопасен: чужие README не затираются.

**Залей в репозиторий:**

```
cd class-repo
git init
git add .
git commit -m "Репозиторий класса: структура, select-me, список учеников"
git branch -M main
git remote add origin <ссылка на репозиторий>
git push -u origin main
```

## 3. Доступ и токен

На общих школьных компьютерах под одной учёткой Windows **все дети ходят в git под одними правами**. Это нормально и даже удобно, но требует одного решения: заведи отдельный **fine-grained токен**, дай ему доступ только к репозиториям класса и больше ни к чему.

Почему так: авторство коммитов задаёт `select-me`, а не токен. Токен отвечает только за право записи. Если токен утечёт, пострадают лишь учебные репозитории — и токен можно отозвать.

На своих ноутбуках дети работают под своими аккаунтами, и токен им не нужен. Поток команд при этом одинаковый — различаются только права.

Токен стоит менять раз в четверть.

## 4. Что проверить до уроков

**До урока 1.** Набор на Диске открывается по ссылке у всех, установщики запускаются без прав администратора. Проверь на одной школьной машине: Python ставится «для текущего пользователя», PyCharm тоже.

Отдельно проверь Git. Если он ставится только с правами администратора, положи в набор **PortableGit** — самораспаковывающийся архив из того же выпуска Git for Windows. Он разворачивается в папку пользователя, прав не требует, а путь до `git.exe` потом указывается в PyCharm в `Settings` → `Version Control` → `Git`.

И не забудь: после установки Git PyCharm нужно перезапустить, иначе его терминал не увидит новую программу. Это первое, что проверяют дети, и первое, на чём они спотыкаются.

**До урока 2.** Репозиторий класса создан и запушен, ссылка скопирована в чат. Проверь, что `select-me` работает: склонируй репозиторий на тестовую машину, запусти `.\select-me`, введи логин из списка и убедись, что `git config --get user.name` печатает имя ученика.

## 5. Про кодировку

`select-me.cmd` написан в UTF-8 и начинается с `chcp 65001`, иначе Windows покажет русский текст кракозябрами. Если в вашей версии Windows это сработает плохо — пересохрани файл в кодировке CP866 и убери строку `chcp`.

Скрипт `select-me` без расширения — для macOS и Linux, там кодировка не проблема.

## 6. Что дальше

Этот репозиторий — для первого блока, где все работают в одной папке и видят друг друга. Когда начнётся pygame, каждый переходит в свой личный репозиторий из шаблона: так у класса не растёт общий вес, а CI у каждого свой. Структура `class-repo` при этом остаётся как есть — она не мешает.
